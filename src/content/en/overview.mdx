Persona is a public, keyless API for coherent fictional people. `GET /people` returns structured names, ages, locations and contact details, with a reviewed portrait when a compatible image is available.

The current response uses schema version **2**. Start with the quickstart, then consult the [full API contract](https://github.com/Osiris-Balonga/persona/blob/dev/docs/api.md) for every filter and field.

> Generated addresses are illustrative. Some generated phone numbers may belong to real subscribers; do not contact them.
