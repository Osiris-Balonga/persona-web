Persona generates coherent fictional profiles for product interfaces and tests. The public v2 API currently exposes one keyless endpoint, `GET /people`. It returns structured identity, location and contact data, plus a reviewed portrait when one is available.

## Start here

1. <Link href="/docs/quickstart">Make your first request</Link> with curl or JavaScript.
2. <Link href="/docs/people">Choose request parameters</Link> for the people you need.
3. <Link href="/docs/response">Read the response and select fields</Link>.
4. <Link href="/docs/errors">Handle errors and rate limits</Link>.
5. <Link href="/docs/replay">Replay seeded requests</Link>.

You can also <Link href="/playground">try the playground</Link> when its live request builder is available.

## Beta endpoint

`https://persona-dev.onrender.com/people`

This is the **staging** API origin for the public beta. Replace it when a production origin is published. The API does not require a key. Browser requests allow `GET` and `HEAD` from any origin without credentials.

## Use generated data responsibly

Profiles are fictional. Addresses are illustrative, and city coordinates do not locate the generated street or a person. Some fallback phone numbers may belong to real subscribers. Do not call, text or email generated contacts; a custom email domain may be live. Portraits can be absent when no reviewed match exists.
